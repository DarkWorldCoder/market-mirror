# Bundled country boundaries

`countries-110m.json` is the unmodified world-atlas 2.0.2 country topology,
derived from Natural Earth 4.1.0 Admin 0 country boundaries at 1:110m scale.

Source: https://github.com/topojson/world-atlas
Download: https://cdn.jsdelivr.net/npm/world-atlas@2.0.2/countries-110m.json
License: ISC, reproduced in `LICENSE.world-atlas`.
Natural Earth data: https://www.naturalearthdata.com/about/terms-of-use/

The world view uses approximate geometric country centers derived from these
boundaries. Avatar spread is a visual layout, not a person's physical location.
Labels without a matching boundary stay in a separate unlocated group. This
small-scale dataset omits some small countries and territories.
