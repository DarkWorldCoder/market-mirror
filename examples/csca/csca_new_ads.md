# CSCA.ai: New Meta Ads to Test

**Campaign setup:** Optimize for Complete Registration (not Landing Page Views). Countries: Nepal, Bangladesh, Indonesia. Use Advantage+ placements, but make vertical 9:16 versions for Instagram. Start with $5–10/day per ad set, let it run 5–7 days, then keep the winners.

**Before launching:** make sure the landing page loads in under 2 seconds on mobile data and shows the sign-up form without scrolling. Only 40% of past clicks became a page view.

**Note:** Use real numbers only in these ads. Don't invent student counts or success rates.
