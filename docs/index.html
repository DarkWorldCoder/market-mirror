Useful questions.
No crystal ball.

Simulation helps you explore a decision. Real customers and real experiments tell you whether it works.

◎

Reactions, not forecasts.

The buyers are AI-generated. Their intent, reactions and projected rates are hypotheses to investigate, not established customer demand.

≠

Disagreement stays visible.

Inspect results by model and audience. In the Fitloop run, the providers wrote and answered for different cohorts; it was not a controlled model comparison.

↗

Check it against reality.

In a retrospective on eight real ads, the simulated click ranking was almost backwards (−0.84 correlation). That failed ranking stays in the evidence.

Make it yours

Your machine.
Your agent. Your market.

Open source and self-hosted. Connect your preferred agent, choose a model provider, and start with a small test.

Add to your client's MCP configuration. Requires uv.
{
  "mcpServers": {
    "market-mirror": {
      "command": "uvx",
      "args": ["--from", "marketmirror==0.4.2", "marketmirror"]
    }
  }
}
From a local clone of the MarketMirror repository.
claude plugin marketplace add "$PWD"
claude plugin install market-mirror@market-mirror
From a local clone of the MarketMirror repository.
codex plugin marketplace add "$PWD"
codex plugin add market-mirror@market-mirror-local
Install the extension from GitHub.
gemini extensions install https://github.com/DarkWorldCoder/market-mirror
Then ask your agent to run doctor and, if needed, setup.Full setup guide ↗

The code is free under AGPL-3.0. Model usage, subscription allowances or local compute can cost money. Requests go to the model provider you configure; optional research accesses public sources.

A few things to know

Good questions.

Still curious? Read the documentation ↗

Are these real buyers or people I can contact?

They are AI-generated characters inside the simulation. Their names, stories, responses and lead scores describe those characters. They are not a contact list of real prospects.

Will MarketMirror run my ads or send emails?

It simulates ads, inbox reactions and sales conversations. It does not publish ads, send outreach or change your ad account.

Is it free?

The source code is available under AGPL-3.0. Running it may consume paid AI usage, subscription allowances or local computing resources; audience size, interview depth, tests and repeats affect the work required.

Do I need to write code?

You can request tests in plain language through a connected AI assistant. Installing MarketMirror, choosing a model and connecting that assistant require technical setup. The command-line tools are also available for direct use.

Can I bring real research and campaign data?

Yes. You can supply product documents, linked feedback and campaign exports, and compare simulations with actual outcomes when you have suitable paired data. Importing an ad export alone does not create a complete validation study.
