# Campaign planning

Call `campaign_plan` with an existing project or product profile, a specific goal, a budget amount and currency, optional channels, and cited research. Review its unknowns and product-supplied claims before using them in copy. Keep the control and treatment, audience, exposure context and outcome metric fixed in each test. Treat equal channel allocation as a draft assumption until real performance data supports a reallocation. Save the plan and run only the tests relevant to the user's decision.
